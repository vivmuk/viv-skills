- `manim-video/legacy-skill.md` — Manim CE animation/explainer pipeline.
- `p5js/legacy-skill.md` — p5.js sketches, export pipeline, viewer template.
- `pretext/legacy-skill.md` — text-layout browser demos and templates.
- `touchdesigner-mcp/legacy-skill.md` — TouchDesigner twozero MCP setup and operator workflows.
