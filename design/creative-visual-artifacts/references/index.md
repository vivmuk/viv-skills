# Creative Visual Artifacts Reference Packages

Absorbed packages are stored as subdirectories under this `references/` folder. Read `legacy-skill.md` inside a package for the former skill instructions, then follow any nested `references/`, `templates/`, `scripts/`, or `assets/` paths relative to that package directory.

- `architecture-diagram/legacy-skill.md` — dark SVG/HTML architecture diagrams; template at `architecture-diagram/templates/template.html`.
- `avatar-logo-design/legacy-skill.md` — avatars, logos, sigils, prompt/fallback workflow.
- `baoyu-infographic/legacy-skill.md` — infographic layout/style catalogs and structured-content flow.
- `claude-design/legacy-skill.md` — one-off HTML artifacts, decks, prototypes, WSL preview notes.
- `design-md/legacy-skill.md` — DESIGN.md token spec authoring and validation.
- `excalidraw/legacy-skill.md` — Excalidraw JSON element schema and upload helper.
- `popular-web-designs/legacy-skill.md` — named web design system templates.
- `sketch/legacy-skill.md` — 2-3 fast HTML mockup variants and README pattern.
