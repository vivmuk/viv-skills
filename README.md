# Viv Skills

A curated collection of AI agent skills for design, productivity, research, and software development.

## Categories

### 🎨 Design
- **viv-design** — UI/UX design system with 22 sub-commands (craft, shape, audit, polish, critique, animate, typeset, layout, colorize, clarify, bolder, quieter, distill, harden, onboard, adapt, optimize, extract, document, init)
- **viv-app-build** — Full-stack app building with grilling-first interview process
- **open-design-first** — Open Design integration for Venice AI-powered design work
- **grilling** — Relentless interview to stress-test plans before building
- **grill-me** — Grilling variant for plan sharpening
- **grill-with-docs** — Grilling that also produces ADRs and glossary docs
- **classical-digital-hybrid-web-design** — Classical fine art + modern digital effects web design
- **creative-visual-artifacts** — HTML/SVG mockups, diagrams, infographics, design systems, logo/avatar design
- **creative-code-motion** — Code-driven generative visuals (Manim, p5.js, ASCII, TouchDesigner)
- **creative-ideation** — Project idea generation via creative constraints
- **pixel-art** — Pixel art with era-specific palettes (NES, Game Boy, PICO-8)
- **baoyu-article-illustrator** — Article illustrations with type × style × palette consistency
- **baoyu-comic** — Knowledge comics: educational, biography, tutorial
